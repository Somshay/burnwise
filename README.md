# BurnWise

ระบบจัดการการเผาในภาคเกษตร · พื้นที่ต้นแบบ อำเภอปาย จังหวัดแม่ฮ่องสอน
(Next.js App Router + TypeScript, ภาษาไทยเป็นหลัก, Light/Dark, responsive)

## วิธีรัน
```bash
npm install
cp .env.example .env.local
npm run dev
```

- `.env.local` ไม่บังคับ ใส่คีย์เฉพาะบริการที่ต้องการ
- เปิดเว็บที่ http://localhost:3000
- Production: `npm run build` แล้ว `npm start`
- ทดสอบบนมือถือในวง Wi-Fi เดียวกัน (ปุ่ม GPS ต้องใช้ HTTPS): รัน `scripts/gen-dev-cert.sh` แล้ว `npm run dev:https` จากนั้นติดตั้งและเชื่อถือใบรับรอง `dev-ca-public/burnwise-dev-ca.crt` บน iPhone


## ฟีเจอร์ที่ทำแล้ว
- **หน้าเดียวสำหรับมือถือ:** แผนที่อำเภอปายก่อน แล้วเลื่อนลงเป็นแดชบอร์ด (ชื่อและค่าของอุณหภูมิ ลม ความชื้น ความกดอากาศ PM2.5 จุดความร้อน)
- **แปลงเผา:** จุดรวมกลุ่มเป็นวงกลมใหญ่ แตะแล้วซูมเข้าจนเห็นแต่ละแปลง แตะแปลงเพื่อดูเงื่อนไข ณ จุดนั้น: **เหมาะสม / ไม่เหมาะสม / ตรวจไม่ได้** พร้อมเหตุผลรายปัจจัย (ความเร็วลม ความชื้น PM2.5 ความกดอากาศ ทิศทางลม)
- **ฉันจะเผาบริเวณนี้ / เผาเสร็จแล้ว:** บันทึกในเครื่องผู้ใช้ (เวลา หมายเหตุ รูปถ่ายไม่บังคับ) ดูได้ที่หน้า `/completed`
- **ปุ่มตำแหน่งของฉัน (GPS):** ซูมไปที่ตำแหน่งผู้ใช้และบอกแปลงที่ใกล้ที่สุด (ต้องเปิดผ่าน HTTPS หรือ localhost)
- ชั้นพื้นที่เกษตรจาก OpenStreetMap, ลูกศรลม, จุดความร้อนเมื่อตั้งค่า FIRMS
- หน้าเดิมที่ยังไม่ได้ลิงก์จากหน้าหลัก: `/map`, `/alerts`, `/profile`

**ข้อควรระวังสำคัญ**
- แปลงเผา 30 จุดใน `src/data/burn-zones.json` และเกณฑ์ใน `src/lib/criteria.ts` เป็น **ข้อมูลตัวอย่าง** ยังไม่ใช่พื้นที่หรือเกณฑ์ทางการ ผลเหมาะสม/ไม่เหมาะสมไม่ใช่การอนุญาตให้เผา
- ยังไม่มี backend/ฐานข้อมูล: ไม่มีการส่ง บันทึกกลาง ตรวจสอบ หรืออนุมัติใด ๆ ทุกอย่างเก็บในเบราว์เซอร์ของผู้ใช้

## แหล่งข้อมูล (ทุกค่าติดป้ายประเภท)
| ข้อมูล | แหล่ง | ประเภท | สถานะ |
|---|---|---|---|
| ลม อุณหภูมิ ความชื้น ความกดอากาศ | Open-Meteo Forecast | แบบจำลอง | ใช้งานได้ ไม่ต้องใช้คีย์ |
| PM2.5 | Open-Meteo Air Quality (CAMS) | แบบจำลอง | ใช้งานได้ ไม่ต้องใช้คีย์ |
| ขอบเขตอำเภอ | OpenStreetMap Nominatim | ข้อมูลแผนที่ | ใช้งานได้ (cache 1 วัน) |
| จุดความร้อน | NASA FIRMS VIIRS | ดาวเทียม | ต้องตั้ง `FIRMS_MAP_KEY` |
| สถานีตรวจวัดจริง | `STATION_API_URL` | ตรวจวัดจริง | ต้องตั้งค่า + ปรับ adapter |

คีย์อ่านเฉพาะฝั่งเซิร์ฟเวอร์ (`src/app/api/*`, `src/lib/sources/*` ใช้ `server-only`) ไม่มีตัวแปร `NEXT_PUBLIC_`

## บริการภายนอกที่ยังต้องตั้งค่า / ยังไม่มี
- `FIRMS_MAP_KEY` (NASA FIRMS, ฟรี), `STATION_API_URL`/`STATION_API_TOKEN` (รูปแบบ JSON ที่คาดหวังอยู่ใน `src/lib/sources/stations.ts`)
- Backend + ฐานข้อมูล (ตารางและคิวการเผา, บทบาท user/admin, ตรวจสอบจากค่าฝุ่น), ระบบสมาชิก/เข้าสู่ระบบ, ระบบส่ง Push/SMS
- ทะเบียนแปลงเกษตร และเกณฑ์การเผาที่หน่วยงานรับรอง
- โลโก้จริง: แทนที่ `public/logo.svg` (ปัจจุบันเป็น placeholder)

ระบบนี้ไม่ยืนยันว่าคำขอได้รับการบันทึกหรืออนุมัติ และไม่ระบุว่าพื้นที่ปลอดภัยต่อการเผา
